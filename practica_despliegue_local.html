La semana anterior experimentamos el despliegue remoto en un servidor de GitHub. En esta práctica bajamos al "terreno de juego" de tu propia máquina: tomarás el control absoluto en local, administrando puertos, resolviendo bloqueos de procesos y conectando Node.js a un motor de base de datos relacional MySQL. Paso 3

Detención, Protocolo de Puertos y Versión Avanzada (awcodeMySQLJoin.js)

1. Detener el servidor con Ctrl + C

En la terminal donde corre el servidor, pulsa Ctrl + C.

⚠️ ¡Atención al Error EADDRINUSE :::3000! (Protocolo de rescate)

Si al intentar arrancar el nuevo script te sale Error: listen EADDRINUSE: address already in use :::3000, el proceso anterior sigue vivo en segundo plano bloqueando el puerto.

Comando para liberar el puerto 3000 de inmediato:

  • En macOS / Linux: kill -9 $(lsof -t -i:3000)
  • En Windows (PowerShell): npx kill-port 3000
🧠 Concepto Clave: ¿Por qué un INNER JOIN y el otro es LEFT JOIN?

En awcodeMySQLJoin.js combinamos 3 tablas en una sola consulta maestra:

SELECT 
    items_join.id AS _id,
    items_join.name AS name,
    lists_join.name AS list_name,
    priorities_join.name AS priority_name,
    priorities_join.badge_color AS priority_color
FROM items_join
INNER JOIN lists_join ON items_join.list_id = lists_join.id
LEFT JOIN priorities_join ON items_join.priority_id = priorities_join.id
WHERE lists_join.name = ?
ORDER BY items_join.id ASC;

1. ¿Por qué INNER JOIN lists_join (Join Normal)?
Porque la relación es estricta y obligatoria. Una tarea no puede existir "en el aire", debe pertenecer por fuerza a una lista válida (list_id NOT NULL). El INNER JOIN exige coincidencia en ambos lados: si la lista no existe, la fila se descarta.

2. ¿Por qué LEFT JOIN priorities_join?
Porque asignar una urgencia es voluntario y opcional (priority_id NULLable). El usuario puede crear una tarea "Sin urgencia".

3. ¿Qué conseguimos con esto?
Con el LEFT JOIN garantizamos que se conserven TODAS las tareas de la tabla izquierda (items_join). Si una tarea no tiene urgencia, sus campos de prioridad valen NULL, pero la tarea se sigue mostrando en pantalla.
¡Peligro si usáramos INNER JOIN para las prioridades! Si pusiéramos INNER JOIN priorities_join, todas las tareas sin urgencia desaparecerían de la vista porque no tendrían correspondencia en la tabla de prioridades.

2. Desplegar la versión avanzada

npm run start:mysql:join

Entra a http://localhost:3000, crea una tarea con urgencia y otra sin urgencia, y luego visita el laboratorio didáctico en http://localhost:3000/comparativa-joins para ver la comparativa de datos devueltos.

Reto de Código Obligatorio

🌟 Mejora de Código: Desplegable de Navegación («Listas tareas de XXX»)

Hasta ahora, para movernos a una lista personalizada teníamos que escribir su URL a mano en la barra del navegador (ej: /trabajo). Como mejora técnica diferencial, debes añadir un menú desplegable en la cabecera que liste todas las listas existentes en la base de datos y que al hacer clic en una, te lleve automáticamente a ella.

🏷️ FACTOR DIFERENCIAL PERSONALIZADO: El desplegable debe titularse obligatoriamente Listas tareas de XXX, donde XXX es tu nombre y apellido real (ejemplo: "Listas tareas de Carlos Gómez").

Paso A: Modificar el Backend (awcodeMySQL.js o awcodeMySQLJoin.js)

En las rutas GET / y GET /:customListName, consulta todas las listas existentes en la base de datos y pásalas a la vista dentro de res.render():

// 1. Obtener todas las listas creadas para el selector
const [allLists] = await pool.query("SELECT name FROM lists ORDER BY name ASC");
// (o 'FROM lists_join' si estás en la versión Join)

// 2. Pasarlas a la vista en res.render:
res.render("list", { 
    listTitle: "Today", 
    newListItems: items,
    allLists: allLists   // 👈 Añadir esta variable
});

Paso B: Modificar la Vista EJS (views/list.ejs)

Abre views/list.ejs y añade el siguiente bloque justo dentro de la caja de cabecera <div class="box" id="heading">, debajo de <h1><%= listTitle %></h1>:

<!-- DESPLEGABLE DINÁMICO DE LISTAS (Personalizado por el alumno) -->
<% if (typeof allLists !== 'undefined' && allLists.length > 0) { %>
  <div style="padding-bottom: 18px; text-align: center;">
    <label for="listNav" style="color: #ffffff; font-size: 13.5px; display: block; margin-bottom: 6px; font-weight: 500;">
      📋 Listas tareas de XXX:  <!-- 👈 REEMPLAZA XXX POR TU NOMBRE -->
    </label>
    <select id="listNav" 
            onchange="if(this.value) window.location.href = (this.value === 'Today' ? '/' : '/' + encodeURIComponent(this.value));"
            style="padding: 7px 12px; border-radius: 8px; border: 1px solid #ccc; font-size: 14px; background: #ffffff; color: #333; cursor: pointer; outline: none;">
      <option value="">-- Selecciona o cambia de lista --</option>
      <option value="Today" <%= listTitle === 'Today' ? 'selected' : '' %>>📅 Today</option>
      <% allLists.forEach(function(l) { %>
        <% if (l.name !== 'Today') { %>
          <option value="<%= l.name %>" <%= listTitle === l.name ? 'selected' : '' %>>
            📌 <%= l.name %>
          </option>
        <% } %>
      <% }); %>
    </select>
  </div>
<% } %>
